# channels.example.txt — full reference for the channels.txt format.
# Copy this to channels.txt and edit. The skill re-reads channels.txt on
# every run.
#
# FORMAT
#   One channel per line. Whitespace-separated tokens:
#     - first token: the channel's @handle (required)
#     - key=value tokens: tags (see below)
#     - anything else: informational, ignored by the parser (URLs, notes)
#   Lines starting with # and blank lines are ignored.
#   A bare key=value line with NO @handle is a global directive.
#
# GLOBAL DIRECTIVES
#   template=finance   Brief style. "finance" (tickers, predictions registry)
#                      or "general" (topics, claims). Default: finance.
#
# CHANNEL TAGS
#   lang=<code>        REQUIRED on every channel row. The language the channel
#                      speaks, e.g. lang=en, lang=ja, or lang=zh (expands to
#                      the whole Chinese family). Pins the caption track and
#                      is the Whisper language hint. Without it, videos with
#                      YouTube auto-dubbing expose ~20 auto-generated tracks
#                      and the wrong one gets picked (e.g. Arabic captions for
#                      an English video). Rows missing lang= are skipped.
#   backend=local      Skip the transcriptapi stage for this channel. Use for
#                      channels where transcriptapi returns empty (usually
#                      captions disabled by the owner) so no credits are
#                      wasted before the local path runs.
#
# EXAMPLES

template=general

# A plain English channel:
@veritasium	lang=en	https://www.youtube.com/@veritasium

# A Japanese channel — prefer Japanese captions:
@NHKWORLDJAPAN	lang=ja

# An English channel with captions disabled — straight to the local path:
@SomeCaptionlessChannel	lang=en	backend=local

# Chinese channel with captions disabled — both tags:
@RhinoFinance	lang=zh	backend=local	https://www.youtube.com/@RhinoFinance
